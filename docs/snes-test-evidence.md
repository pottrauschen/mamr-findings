# SNES test evidence register

Every test program that MAMR's SNES path runs or compares against, with
what its expected values rest on. The rule (docs/snes-hardware-spec.md
section 5.18, from the second research pass of 2026-10-24): neither a
project description nor "runs on hardware" makes a test's expected
values TEST-ROM-HW; that class needs a console result (a photograph, a
log, a trace) with the board revision. Without it a test counts as DOC
(the author's documented expectation), EMU-CONSENSUS (the emulators
agree) or model data. Classes as in docs/snes-hardware-spec.md.

Columns: test id (as the ctest or the file is named); source and
commit; licence; origin of the expected values; board revision of the
console run, if any; raw data available; emulator comparison done here;
where it is used.
